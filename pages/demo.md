# Порядок работы программы

Программа показывает работу классов на заранее заданных примерах. Ввод с клавиатуры не требуется

Сначала создаются белая ладья, черный слон, белый конь, черный ферзь и два короля разных цветов. Они передаются доске через вектор ChessPiece*. Виртуальный printInfo() выводит данные каждого конкретного типа

Белые фигуры обозначаются заглавными буквами, черные — строчными. Столбцы и строки имеют координаты от 0 до 7, строка 0 выводится внизу. Точка обозначает пустую клетку

Затем программа обращается к ферзю через CombinedPiece*. Вызов показывает объединенное движение по прямой и диагонали без учета других фигур

На доске выполняются разрешенные и запрещенные ходы. Ладья не проходит через коня, конь перепрыгивает на свободную клетку. Слон ходит по диагонали и возвращается обратно. Ладья не проходит через черного слона, но может взять его. Король ходит на одну клетку, ферзь — по прямой. Выход за границы отклоняется

После ходов выводится доска. Создается пример с двумя белыми королями: статическая validateBoardState() возвращает false, а конструктор Board выбрасывает исключение. Ошибка выводится, программа продолжает работу

Дальше отдельно для каждого типа показаны копирование, присваивание фигуре другого цвета и самоприсваивание. Копия перемещается, исходный объект сохраняет позицию. На доску эти отдельные примеры не помещаются

В конце создается ладья с координатой 8. Конструктор отклоняет ее, счетчики сохраняются. Затем динамический ферзь удаляется через ChessPiece*: виртуальный деструктор уменьшает счетчик черных фигур

После уничтожения всех объектов счетчики белых и черных фигур равны нулю. Программа возвращает код 0

Модель упрощенная: нет очередности ходов, шаха, мата и рокировки. Правила занятости клеток и препятствий применяются в Board::movePiece(). Метод ChessPiece::moveTo() отдельно от доски проверяет только движение самой фигуры
