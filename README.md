# Лабораторная работа №4

## Описание

Вариант 4 — Шахматные фигуры

Лабораторная работа посвящена наследованию и полиморфизму в C++

Стандарт языка: C++14

Документация создаётся с помощью Doxygen, диаграмма классов — PlantUML

## Часть 7

Реализован абстрактный класс `ChessPiece`, который хранит цвет и позицию фигуры

Добавлены чисто виртуальные методы `canMoveTo()` и `getSymbol()`, виртуальный вывод информации, виртуальный деструктор и метод выполнения хода

При неправильных координатах или цвете конструктор выбрасывает исключение. Неправильный ход не меняет позицию

Цвет и позиция копируются независимо. Отдельные статические счетчики учитывают существующие белые и черные фигуры

Добавлен промежуточный абстрактный класс `SlidingPiece` с общими правилами движения по прямой и диагонали. От него наследуются ладья `Rook` и слон `Bishop`

Добавлены абстрактный `JumpingPiece` и конь `Knight`. Конь ходит буквой Г: две клетки по одной оси и одна по другой

Добавлен ферзь `Queen`, который наследуется от `SlidingPiece` и интерфейса `CombinedPiece`. Он объединяет движение по прямой и диагонали

Добавлены король `King` и доска `Board`. Король ходит на одну соседнюю клетку. Доска хранит `ChessPiece*`, учитывает занятые клетки, препятствия и взятие чужой фигуры

Статическая `ChessPiece::validateBoardState()` отклоняет пустые и повторные указатели, совпадающие позиции и двух королей одного цвета. Пустая доска и позиции без королей допускаются

В программе показаны ходы через `ChessPiece*` и обращение к ферзю через `CombinedPiece*`. Все конкретные фигуры переопределяют вывод информации. Полная проверка шаха, мата и очередности ходов не выполняется

Проверки находятся отдельно в `tests/main.cpp`

Для ладьи, слона, коня, ферзя и короля показаны копирование, присваивание, самоприсваивание и независимое перемещение копии. При присваивании фигуре другого цвета обновляются общие счетчики

Итоговая программа также показывает исключения при создании неправильной фигуры и доски, а затем удаление ферзя через базовый указатель. После завершения примеров оба счетчика равны нулю

## Сборка и запуск

Нужен компилятор `g++` в PATH

```powershell
.\build.bat
.\build\lab4.exe
```

Ввод с клавиатуры не требуется: программа выполняет демонстрационные примеры и завершается. Для просмотра вывода нужно запускать exe из PowerShell или терминала

Отдельная программа с проверками:

```powershell
.\build\lab4-tests.exe
```

## Создание документации

Нужен установленный Doxygen

```powershell
.\docs.bat
```

Открыть `docs/html/index.html`

Для перерисовки UML можно использовать редактор с PlantUML или Java:

```powershell
java -jar plantuml.jar -tsvg uml/chess.puml
```
